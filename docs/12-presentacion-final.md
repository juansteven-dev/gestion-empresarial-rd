# Presentación final (PowerPoint)

Propuesta de 10-12 diapositivas:

1. Portada: nombre, asignatura, integrantes y fecha.
2. Problema: contexto, causas y consecuencias.
3. Objetivo y alcance: qué resuelve y qué queda fuera.
4. Usuarios y requisitos: roles y requisitos prioritarios.
5. Arquitectura cliente-servidor: React, API, SQL Server.
6. Diagramas/modelo de datos: UML y ER.
7. Interfaces: capturas reales de las pantallas.
8. Demostración: iniciar sesión, registrar compra y venta, mostrar stock actualizado.
9. Seguridad y pruebas: roles, transacciones, casos ejecutados y evidencias.
10. Resultados: funciones implementadas y limitaciones.
11. Conclusiones y mejoras futuras.
12. Créditos/referencias breves.

Cada integrante debe explicar su responsabilidad y mostrar una contribución comprobable. Ensayar la demostración con base de datos restablecida y usuarios ficticios.
