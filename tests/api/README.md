# Pruebas de API

Guardar aquí la colección Postman exportada y un archivo de variables de entorno de ejemplo sin secretos. La colección debe organizarse por Auth, Catalog, Suppliers, Purchases, Sales, Inventory, Reports y Audit.

Usar variables como `baseUrl`, `adminCookie` (solo durante sesión local, no versionar valores), `productId`, `supplierId`, `purchaseId` y `saleId`.
